# Bitácora de Aprendizaje

Lector de cursos tipo libro, con evaluaciones y repasos espaciados. Se instala en el iPhone desde Safari: *Compartir → Agregar a pantalla de inicio*.

- `index.html`: la app.
- `cursos/indice.json`: lista de cursos, en orden.
- `cursos/<id>.json`: cada curso, con sus capítulos y su banco de preguntas.

El avance se guarda en el dispositivo.
